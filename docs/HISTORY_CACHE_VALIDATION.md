# 对话历史缓存验收（2026-09-28）

交付版本：`1.8.124+256`。

用户日志中，首次打开 140 条记录约 5 秒；之后已有 140 条内存缓存，快速退出重进仍反复下载，
最终一次等待约 17.7 秒。此次改动减少重复历史传输，不改模型上下文、SSH 配置或连接弹窗。

## 行为与保护

- 同 lane、连接代次、线程、权限和读取模式的在途请求共享；切页只改变呈现目标。
- 有完整同代实时缓存时，仍以 `thread/resume` 检查原生 writer，但省略历史正文；保留游标、
  TokenUsage、回合起点，并重放校验期间的消息。断线、协议错误、会话关闭、缓存淘汰或权限变化后重新读取。
- 冷启动并行读取压缩加密快照与服务器；本地预览不会解锁输入或恢复审批，迟到结果不能覆盖当前页面。
- gzip + AES-256-GCM 在独立 isolate 执行；系统安全存储保存主密钥，随机 nonce，scope/thread 参与认证。
  默认最多 16 份、密文总量 8 MiB、单份 1 MiB、展开 4 MiB、7 天过期；写入合并且队列有界。
- 服务器连接身份、Agent、Provider 和 thread 隔离；归档、回退、删除服务器及身份变更清除对应缓存。
- 子 Agent 和被其他客户端占用的会话继续通过只读协议更新；缓存不能绕过只读限制。
