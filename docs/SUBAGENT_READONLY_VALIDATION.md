# 子 Agent 只读详情验收（2026-09-20）

目标版本：`1.8.112+242`。按用户的桌面参考调整活动行、子线程标题、历史隔离和只读页面。

## 行为

- 父时间线保留每次开始、完成、发送消息的原始位置，使用安静的图标/名称/动作行；后台索引继续按 child ID 合并。
- 子页面使用该 Agent 名字与同身份图标，底部留空。输入、发送、停止、权限、模型、审批和线程修改不显示，控制器也拒绝这些修改。
- 子页恢复、缓存初显、分页及实时/后台回放共同排除已知父回合；合法 UUIDv7 时间补足缺失/同秒时间戳。普通 fork 的原历史保持。
- 发给父线程的协作消息显示“已向父代理发送消息”，不把父线程计为子 Agent，也不提供点击操作。
- 子页只读调用 `thread/read` 和最近四回合分页；大响应降级页数/详情，旧版分页方法不存在时回退完整 read。普通父会话继续 resume。

## 真实 API 证据和用量

`scripts/test-codex-subagents-live.cjs --live --history` 创建独立父任务和一个子任务，私有认证目录结束后清理，
不改原 URL/Key/配置或用户会话。首次尝试发现卸载状态的 v2 child `thread/resume` 返回 `-32600`；
第二次验证重启后 `thread/read` 与分页成功，先恢复父任务后 child resume 才成功。

真实样本中没有复现 root 混入：重启前后均只有一个 child turn。历史污染缺陷由受控旧格式/缓存样本验证，
不能把单一版本的真实样本解释成所有版本都无该问题。脱敏样本为
`flutter_app/test/fixtures/subagent_child_history_live.json`，保留相对 UUIDv7 时间和字段结构。

两次调用合计协议统计 `199651` tokens，其中缓存输入 `82795`；这不等于账单金额。后续仅回放样本，
没有继续调用付费 API。没有创建 Git 标签或触发云端构建。
